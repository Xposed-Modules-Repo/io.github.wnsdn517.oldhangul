# 삼성 키보드 옛한글 (LSPosed 모듈)

삼성 키보드(Samsung Keyboard / HoneyBoard)의 **두벌식 한국어 자판**에 다음 기능을 더하는 LSPosed 모듈입니다.

| 기능 | 예 |
| --- | --- |
| 옛한글 조합 | `ㅂㅅㄱ`+`ㅏ` → ᄢᅡ, `ㅂㅇ`+`ㅏ` → ᄫᅡ, `ㄱ`+`ㆍ`+`ㄹ` → ᄀᆞᆯ, `ㅿ`+`ㅏ` → ᅀᅡ |
| 자동 ㅇ 채우기 | `ㅏ`+`ㄴ` → 안, `ㅏ`+`ㄹ`+`ㄱ` → 앍 (`ㅏㅏㅏㅏ`는 그대로) |
| ㅋ 길게 누르기 | 누르고 있는 동안 `ㅋㅋㅋㅋ…` 계속 입력 |
| 옛 자모 길게 누르기 | ㄹ → ㅿ, ㅇ → ㆁ, ㅎ → ㆆ, ㅏ → ㆍ (ㄱㄷㅂㅅㅈ 은 삼성 기본 쌍자음 그대로) |
| 백스페이스 재조합 | 안 ⌫ → 아 (옛한글 음절도 자모 단위로 지움) |

기준 버전: Samsung Keyboard **5.9.40** (HoneyBoard-548300). 다른 버전도 동작하도록
난독화된 클래스를 이름이 아닌 로그 문자열로 찾습니다(아래 “동작 방식” 참고).

## 설치

1. LSPosed(Zygisk) 가 설치된 루팅 기기에 APK를 설치합니다.
   - Actions 탭의 **Build** 워크플로 결과물(`SamsungKeyboardOldKorean-apk`) 또는 직접 빌드: `./gradlew :app:assembleRelease`
2. LSPosed 관리자에서 모듈을 켜고 범위에 **삼성 키보드(com.samsung.android.honeyboard)** 를 선택합니다.
3. 삼성 키보드를 강제 종료(또는 재부팅)합니다.
4. 앱 서랍의 **삼성 키보드 옛한글** 에서 기능을 켜고 끌 수 있습니다. 설정은 키보드를 다시 열 때 적용됩니다.

옛한글이 보이려면 옛한글 조합형 자모를 그릴 수 있는 글꼴이 필요합니다(예: Noto Sans CJK KR, 함초롬). 글꼴이 지원하지 않으면 자모가 풀어진 채로 보이지만 입력된 텍스트 자체는 올바릅니다.

## 입력 규칙

- **자음만 연달아 치면 합쳐지지 않습니다**: `ㅎㅎ`, `ㅋㅋ`, `ㅂㅅ` 그대로.
- **초성 없는 모음은 현대 겹모음만 합쳐집니다**: `ㅗㅏ` → ㅘ, 하지만 `ㅜㅜ`, `ㅡㅡ`, `ㅏㅏㅏㅏ` 는 그대로.
- **옛한글 조합이 켜져 있으면** 모음 앞의 자음 묶음이 옛 초성이 됩니다(`ㅅㄱㅏ` → ᄭᅡ), 초성 뒤 모음 묶음도 옛 중성이 됩니다(`ㄱㅜㅜ` → ᄀᆍ). 끄면 현대 한글 음절만 조합합니다.
- 받침 뒤에 모음이 오면 마지막 자음 하나가 다음 음절 초성으로 넘어갑니다(도깨비불): `ㄷㅏㄹㄱㅏ` → 달가.
- 끝난 음절은 곧바로 확정(commit)되고, 바뀔 수 있는 마지막 음절만 조합 중으로 남습니다.

## 동작 방식

삼성 키보드는 한글 조합을 네이티브 XT9 엔진(`libXt9core.so`)에서 하므로 옛한글을 만들 수 없습니다.
그래서 이 모듈은 두벌식 자모 키 입력을 가로채 자체 조합기로 처리합니다.

- `engine/` — 안드로이드 의존성이 없는 순수 Java 조합기(`HangulComposer`)와 단위 테스트.
  조합표(`JamoTables.java`)는 `tools/gen_jamo_tables.py` 가 유니코드 자모 이름(예: `HANGUL CHOSEONG PIEUP-SIOS-KIYEOK` → ㅂㅅㄱ)에서 자동 생성합니다.
- `app/` — LSPosed 모듈. [DexKit](https://github.com/LuckyPray/DexKit)으로 난독화된 대상을 찾아 훅합니다.

| 훅 대상 | 찾는 방법 (5.9.40 에서의 이름) |
| --- | --- |
| 키 이벤트 객체 | `"KeyRequestInfo{mKeyCode="` 를 쓰는 클래스 (`Dm.b`) |
| 키 액션 실행기 | `" execute end t : "` 를 쓰고 인자 2개인 메서드 (`Fl.d.d`) — 액션 이름(`CharacterKeyA`, `BackspaceKeyA` …)으로 분기 |
| 글자 입력 명령 | `"input_key_chn_dot"`, `"input_key_repeatable_up"` 를 쓰는 메서드 (`Cl.H.c`) — 모듈이 처리한 키는 이 명령만 꺼서, 진동·소리·쉬프트 해제·자판 갱신은 삼성 코드가 그대로 처리 |
| 키 누름/뗌 | `"onTalkBackClick: xy = ("` 메서드가 호출하는 같은 클래스의 1-인자 메서드 (ㅋ 반복 멈춤용) |
| 키 롱프레스 | `"onTalkBackLongClick: xy = ("` 메서드가 호출하는 같은 클래스의 1-인자 메서드 (`ep.a.e`) |
| 커서/조합 영역 | `HoneyBoardService.onUpdateSelection` 등 (난독화 안 됨) |

찾은 결과는 키보드 데이터 폴더(`files/oldhangul_targets.properties`)에 APK별로 캐시됩니다.
문제가 생기면 LSPosed 로그에서 `OldHangul:` 로 시작하는 줄을 확인해 주세요.

### 알려진 제한

- **두벌식(쿼티) 전용**입니다. 천지인·나랏글 등은 자동 감지해서 삼성 기본 동작으로 넘기지만, 단모음 쿼티 자판은 아직 구분하지 못합니다.
- 모듈이 한글 조합을 맡는 동안에는 삼성 키보드의 **한국어 추천 단어/자동 수정이 나오지 않습니다**.
- 기기에서 직접 검증하지 못한 부분: 롱프레스를 건너뛴 뒤 키를 뗄 때의 처리, 일부 앱(웹뷰 등)의 조합 영역 처리.
- 받침과 옛 초성 묶음이 겹치는 경우(`ㅇㅏㅆㅅㅣ` → 았시 / 아ᄴᅵ, `ㄹㅇㅔ` → ᄛᅦ / ㄹ에)는 지금은 받침을 우선합니다. 고르는 방법은 아래 계획 2번 참고.
- 하드웨어 키보드 입력은 건드리지 않습니다.

## 다음 기능 계획

1. **키보드 안에서 옛한글 모드 켜고 끄기** — 한자 키나 스페이스바 제스처로 즉시 전환, 상태를 키 라벨/토스트로 표시(지금은 설정 앱에서만 전환).
2. **겹자음 모호성 해결** — `았시`/`아ᄴᅵ`, `ᄛᅦ`/`ㄹ에` 처럼 두 가지로 읽히는 입력을 고르는 방법. 후보: (A) 일단 최대한 합치고 스페이스 한 번이면 풀기, (B) 추천 단어 줄에 두 후보 표시, (C) 같은 자음 연타/쉬프트 조합만 옛 초성으로 합치기.
3. **옛 자모 롱프레스 팝업** — 한 키에 여러 옛 자모(ㅇ → ㆁ, ㆀ / ㅏ → ㆍ, ᆢ)를 고르는 삼성 스타일 팝업, 사용자가 직접 매핑 편집.
4. **ㅋ 롱프레스 확장** — 누르고 있는 동안 ㅋ 반복 입력, ㅎ·ㅠ·ㅜ 등 다른 키에도 반복 문자 지정.
5. **삼성 추천 단어 연동** — 조합 중인 현대 한글을 삼성 예측 엔진에 넘겨 추천 단어 복원, 옛한글 사전(훈민정음·용비어천가 어휘) 추천.
6. **천지인·단모음 쿼티 지원** — 자판 종류를 삼성 설정값에서 직접 읽고, 천지인용 옛한글 조합(ㆍ 세 번 → ᆢ 등) 추가.
7. **옛한글 한자 변환** — 한자 키로 옛한글 음 → 한자 후보.
8. **표시 글꼴 도우미** — 옛한글 글꼴 설치 여부 확인과 안내.
9. **다른 삼성 키보드 버전 검증** — 버전별 훅 대상 자동 점검 화면과 오류 보고.
